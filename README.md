# 서재 (epub 웹 서재)

epub 파일을 GitHub 저장소에 등록해두면 웹사이트에 책 목록으로 나타나고,
제목을 클릭하면 다운로드 없이 브라우저 안에서 바로 열리는 아주 단순한 정적 사이트입니다.

빌드 도구나 서버가 필요 없습니다. HTML/CSS/JS 파일뿐이라 GitHub Pages로 그대로 배포됩니다.

## 사용 방법

### 1. 책 추가하기

1. `epubs/` 폴더에 `.epub` 파일을 넣습니다.
2. 저장소 최상위의 `books.json`을 열어 아래 형식으로 항목을 추가합니다.

```json
[
  {
    "title": "책 제목",
    "author": "지은이 (선택 사항)",
    "file": "epubs/파일이름.epub"
  }
]
```

- `title`: 책장에 표시될 제목입니다.
- `file`: `epubs/` 폴더 기준 상대경로입니다. 파일명과 정확히 일치해야 합니다.
- 여러 권을 추가하려면 배열에 객체를 계속 이어서 넣으면 됩니다.

### 2. GitHub Pages로 배포하기

1. 이 폴더 전체를 GitHub 저장소에 푸시합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로, 브랜치는 `main` (또는 사용 중인 기본 브랜치), 폴더는 `/ (root)`로 설정합니다.
4. 몇 분 뒤 `https://사용자이름.github.io/저장소이름/` 주소로 사이트가 열립니다.

이후 `epubs/`에 파일을 추가하고 `books.json`을 수정해 커밋 · 푸시할 때마다
사이트가 자동으로 갱신됩니다.

## 폴더 구조

```
.
├── index.html          # 책장 목록 페이지
├── reader.html          # epub 리더 페이지
├── books.json           # 책 목록 데이터 (여기만 수정하면 됨)
├── epubs/                # 실제 epub 파일들을 넣는 곳
└── assets/
    ├── style.css
    ├── app.js           # 책장 렌더링
    └── reader.js        # epub.js 기반 리더 로직
```

## 동작 원리

- 책 목록은 순수 정적 파일인 `books.json`을 읽어서 그립니다. 서버나 데이터베이스가 없습니다.
- epub 렌더링은 오픈소스 라이브러리 [epub.js](https://github.com/futurepress/epub.js)를 CDN으로 불러와 사용합니다.
- 책마다 제목을 해시해 책등 색을 자동으로 정하므로, 책이 늘어나도 손댈 게 없습니다.

## 참고 / 제약

- epub 파일 용량이 크면(수십 MB 이상) GitHub 저장소 용량 제한에 유의하세요.
- DRM이 걸린 epub(구매한 전자책 등)은 열리지 않습니다. DRM이 없는 epub만 지원합니다.
- 한글 파일명도 되지만, 문제가 생기면 영문/숫자 파일명을 권장합니다.
